Propunere proiect: SportBuddy
SportBuddy este o aplicație web pentru găsirea terenurilor sportive și organizarea de meciuri locale la care se pot înscrie alți utilizatori.

Funcționalități principale
autentificare și profil de utilizator;
hartă cu terenuri de baschet, tenis și fotbal;
creare, modificare și ștergere meciuri;
înscriere/anulare înscriere la un meci;
afișarea locurilor disponibile și a jucătorilor înscriși;
rating pentru seriozitate după meci;
chat între participanții la același meci;
filtrare după sport, distanță, dată și nivel de joc.
Împărțirea muncii — 70% / 30%
Studentul 1 — tu, aproximativ 70%
Coordonare și arhitectură

definirea cerințelor și a cazurilor de utilizare;
proiectarea bazei de date și a arhitecturii aplicației;
configurarea proiectului, autentificării și rolurilor;
integrarea frontend–backend;
documentația principală și pregătirea prezentării.
Funcționalități implementate

înregistrare, autentificare și profil;
harta terenurilor sportive;
adăugare și afișare terenuri;
crearea și administrarea meciurilor;
înscrierea utilizatorilor la meciuri;
căutare și filtrare meciuri;
validări, gestionarea erorilor și securitate de bază;
teste pentru funcțiile principale.
Studentul 2 — aproximativ 30%
Funcționalități implementate

interfața pentru lista participanților;
chat-ul asociat unui meci;
sistemul de rating/review;
afișarea istoricului meciurilor și a reputației;
câteva teste pentru chat și rating;
contribuție la documentație și prezentare.
Pentru ca împărțirea să fie echitabilă, studentul 2 poate primi un modul complet și clar delimitat: chat + reputație, iar tu păstrezi integrarea, funcționalitățile centrale și arhitectura.

Module recomandate
User Management — conturi, autentificare, profil.
Sports Locations — terenuri și hartă.
Games — creare și înscriere la meciuri.
Chat — conversații între participanți.
Reputation — rating după participare.
Notifications — opțional, pentru confirmări și modificări.
Tehnologii potrivite
Frontend: React sau Angular;
Backend: Node.js + Express;
Bază de date: PostgreSQL;
Hartă: Leaflet + OpenStreetMap;
Chat: WebSocket/Socket.IO;
Autentificare: JWT;
Testare: Jest și Supertest;
Versionare: GitHub cu branch separat pentru fiecare student.
MVP pentru proiect
Pentru o variantă realizabilă la Inginerie Software, păstrați obligatoriu: autentificare, hartă, creare meci, înscriere, chat și rating. Notificările push, aplicația mobilă și plățile pot fi trecute la funcționalități viitoare, nu implementate în prima versiune.
